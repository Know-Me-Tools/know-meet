## Why

Participants need visible controls for screen sharing and chat, with every message's audience explicit, and a way to start audio when autoplay is blocked.

## What Changes

- Share control and share tile following the meet prototype
- Chat panel with Everyone and private audiences, labelled on every message
- Enable audio prompt when playback is blocked

## Capabilities

### New Capabilities

- `conferencing-room-ui`: Room UI exposes share, chat and audio start

### Modified Capabilities

- None
