# CSP for agentic media, gate 16.5 (apps/web side)

Static inspection only (VLBV). The policy strings below come from running the pure
function `buildContentSecurityPolicy` with `node --experimental-strip-types`; no
build, lint, typecheck or test ran on product code.

Source of truth: `apps/web/scripts/content-security-policy.ts`. It feeds the web
meta tag (`apps/web/vite.config.ts`) and the Tauri `--config` merge
(`apps/desktop/scripts/tauri-cli.ts`). `tauri.conf.json` holds the static fallback.

## Findings addressed (from comparison.md, CSP findings)

| Violation | Cause | Resolution |
|---|---|---|
| `img-src` / `media-src` blocked the allowed media origin | Origin was not in the policy | `KM_MEDIA_ORIGINS` adds validated origins to `img-src` and a new `media-src` |
| `font-src data:` (KaTeX_Size3 woff2 inlined by Vite) | `assetsInlineLimit` inlined the font | Policy keeps `font-src 'self'`. KaTeX fonts must be self-hosted files (no `data:` fonts). Needs a build config follow-up, see below |
| `script-src eval` (58 per run) | zod 4 `allowsEval` probe `try { Function("") } catch` | Harmless: caught, zod uses its non-JIT path. No `'unsafe-eval'`; documented in a code comment |

## Before / after (no env set)

Before:

    default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; font-src 'self'; connect-src 'self' ipc: http://ipc.localhost

After:

    default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; media-src 'self'; font-src 'self'; connect-src 'self' ipc: http://ipc.localhost

With `KM_MEDIA_ORIGINS=https://media.example.com`:

    default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data: https://media.example.com; media-src 'self' https://media.example.com; font-src 'self'; connect-src 'self' ipc: http://ipc.localhost

With `KM_MEDIA_ORIGINS="https://media.example.com, HTTPS://cdn.example.org:8443,http://127.0.0.1:4317,https://media.example.com"`
(whitespace trimmed, lowercased, duplicate dropped):

    ... img-src 'self' data: https://media.example.com https://cdn.example.org:8443 http://127.0.0.1:4317; media-src 'self' https://media.example.com https://cdn.example.org:8443 http://127.0.0.1:4317; ...

`data:` stays on `img-src` only (it was already there); `media-src` never gets it.
`connect-src` is unchanged and independent of media origins.

## Validation rules (`mediaOrigins`)

Unset or blank gives no extra origins. Otherwise comma-separated; each entry is
trimmed and lowercased, and must be exactly `scheme://host[:port]`:

- `https://` for any host; `http://` only for `127.0.0.1` or `localhost` (dev).
- No path (including a trailing `/`), query, fragment, credentials or wildcard.
- No other scheme, no scheme-less host, port at most 65535, no empty list entry.
- Any invalid entry throws, so the build or `tauri` wrapper fails loudly.
